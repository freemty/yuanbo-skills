# swiss-knife-design

Personal web design system for Yuanbo Yang's projects.

Use when building or reviewing project pages, dashboards, leaderboards, slides, or visual assets that should use Yuanbo's black/white/red visual identity.

## Install

Use the repo installer:

```bash
./install.sh --target codex
```

Manual Codex install:

```bash
ln -sf "$(pwd)" ~/.agents/skills/swiss-knife-design
```

## Files

- `templates/base.css` — full homepage CSS reference
- `templates/design-tokens-override.css` — drop-in token override
- `templates/tokens.json` — machine-readable tokens
