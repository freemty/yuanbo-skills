# yuanboizer-zh

Chinese draft polisher for Yuanbo's personal voice.

Use when polishing Chinese notes, posts, or drafts while preserving the original stance, emotion, and compressed style.

## Install

Use the repo installer:

```bash
./install.sh --target codex
```

Manual Codex install:

```bash
ln -sf "$(pwd)" ~/.agents/skills/yuanboizer-zh
```
